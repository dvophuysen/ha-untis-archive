Transcribe one physical textbook vocabulary page from its original image. The upper and lower views overlap: read the overlap only once. Work from top to bottom, and within a multi-column box read the entire LEFT column top to bottom before the next column. Do not interleave columns.

FIRST distinguish page furniture from real headings. The top strip containing Vocabulary, V, a unit number, or the name of the ongoing unit is a RUNNING HEADER. It is never an opening event. A plain vocabulary table with horizontal row separators is NOT a box. A box is a separately bounded rectangle containing its own small word list. Yellow explanatory text in the example column is not a vocabulary box. Marginal exercise numbers are references, not chapter headings. Use a descriptive label 'Untitled box (exercise N)' if a real framed word box has no title; do not pretend its first vocabulary word is a heading.

Read only FOREIGN HEADWORD + GERMAN MEANINGS + PRINTED GRAMMATICAL ANNOTATIONS. Never create a row from the example/rightmost explanatory column, word-family arrows, phonetic/abbreviation legends, grammar demonstrations, exercises, or an alphabetical dictionary. Do not transcribe example sentences: set example to an empty string. A wrapped entry is still ONE entry: for instance infinitive and printed past tense on the next line within the SAME ruled row belong together, the past tense goes into grammar. Separate inflected forms ONLY when they occupy their own actual vocabulary entry with their own translation (e.g. Latin est and sunt). Keep no-pl, sg, pl, AE and similar annotations in grammar, not the headword. Keep optional meaningful particles in the headword. Do not add grammar knowledge absent from the image. Undo typographical line-break hyphenation in German, preserving genuine hyphens.

Every bilingual word in a framed box must be transcribed. When a printed list enumerates individually translated items, output those items separately in source order. For a monolingual box, retain ALL original terms/phrases in reference_boxes, with its title and insertion index; never invent German meanings or put empty translations in rows. Include both members of noun/verb pairs in monolingual boxes. Retain repeated headwords at every occurrence.

Real BODY headings start new units/sections. 'Station 1', 'Station 2', 'Station 3', 'Story', 'Check-out', 'Introduction', 'Texto A' and 'Texto B' are sections, not units. Body Unit N, Unidad N, Welcome back!, Media smart, Text smart, Across cultures are independent units. Use the actual visible title, never the word 'verbatim'. A heading does not end at the bottom of a page: do NOT emit close events for units/sections. Emit a box close exactly BEFORE the first row outside its lower border. A first row without a BODY heading is a continuation even if a running header is present.

Return JSON with printed_page (actual footer integer or null), running_headers (strings), elements (an array in exact reading order), issues. IMPORTANT: DO NOT compute row indexes, counts or offsets. Express boundaries as standalone elements interleaved with the words.

Do not give type word to examples or untranslated reference-box items.
